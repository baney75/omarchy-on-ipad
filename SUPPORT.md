# Support

This is a research project, not an installer or supported operating-system distribution.

- For a bounded task or sanitized device result, use the issue forms.
- For a possible vulnerability, privacy leak, unsafe device operation, or credential exposure, follow [SECURITY.md](SECURITY.md).
- For Omarchy usage on supported hardware, use the official [Omarchy repository](https://github.com/omacom/omarchy).
- For Asahi Linux support on supported Macs, use the official [Asahi Linux documentation](https://asahilinux.org/docs/).

There is currently no native iPad installation procedure to support.
