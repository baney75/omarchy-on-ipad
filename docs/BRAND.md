# Public identity guide

## Position

For Apple-silicon iPad owners and open-source systems engineers, this project is the evidence-driven coordination hub that shows the real path to native Omarchy, unlike one-off demos or speculative installer claims.

The displayed title is **Omarchy on iPad — Unofficial Community Research**. `Omarchy` is used descriptively, not claimed as this project's mark. Keep the unofficial label visible wherever the title appears.

## Voice

- Say what passed, where, and on what exact scope.
- Say “not yet” plainly when evidence is missing.
- Invite one bounded contribution at a time.

Do not use launch hype, jailbreak slang, fear language, fake percentages, or claims that a prepared artifact ran on hardware.

## Mark

The original mark is a rounded device/window frame with a gap in its lower edge. A path rises through the gap and turns toward a horizon that stops short of the frame. The open gap represents the unresolved native-entry path.

Assets:

- `site/assets/mark.svg` — chartreuse project mark;
- `site/assets/mark-mono.svg` — one-color `currentColor` mark;
- `site/assets/wordmark.svg` — project mark plus descriptive title;
- `site/assets/favicon.svg` — dark-canvas browser icon.

Use at 24 px or larger for the standalone mark. Leave clear space equal to one quarter of the mark's width. Do not rotate, stretch, add effects, place inside an Apple silhouette, combine with an Apple or Omarchy logo, or recolor it to imitate another project.

## Palette

| Role | Hex | Use |
| --- | --- | --- |
| Canvas | `#0f1113` | Primary background |
| Surface | `#15181b` | Current-truth panel only |
| Ivory | `#f3eee4` | Main text; 16.4:1 on canvas |
| Muted | `#b3ada2` | Secondary text; 8.5:1 on canvas |
| Faint | `#8f8a81` | Metadata only; 5.5:1 on canvas |
| Chartreuse | `#c8f03c` | Verified/live signal |
| Periwinkle | `#a3adff` | Links and active work |
| Amber | `#f0b44c` | Prepared work |
| Coral | `#ff8a76` | Blocked or risk state only |

All shipped body-text pairs meet WCAG AA on the canvas. Color never carries state alone; the dashboard also prints a label and uses a distinct glyph.

## Typography and layout

Use the platform system sans and monospace stacks. Do not load remote fonts. Prefer crisp editorial hierarchy, 4 px spacing increments, restrained 4/8 px radii, visible rules, and generous whitespace. Preserve the tested 390 px and 1280 px layouts, keyboard focus, and reduced-motion behavior.
