## Forum or chat version

I’m opening an evidence-driven community effort to run Omarchy natively on Apple-silicon iPads. The reference device is an M1 iPad Pro, but the repository is built so owners of other M-series iPads can add sanitized device/build results and work on their own hardware.

The dashboard distinguishes prepared work, offline verification, physical verification, and completion. It shows exact milestone counts, live workstreams, blockers, recent results, and device coverage. The public lane is read-only; possible boot-chain or security findings use private coordinated disclosure.

The biggest needs are Apple boot-chain/security research, m1n1 and Asahi experience, Linux device-tree and driver work, DCP/display, touch/Pencil, power/networking, and Arch/Omarchy packaging. Humans, GPT-6 Daybreak, Claude Code, and local agents can contribute under the same `AGENTS.md` contract.

Repository: https://github.com/baney75/omarchy-on-ipad  
Dashboard: https://baney75.github.io/omarchy-on-ipad/

Please share it with people who own the hardware or know the stack.
